Artificial Intelligence Archaeology Anomaly Detection Application (Python)

This application is the product of a Master Degree in Artificial Intelligence.

The application is an End-To-End ML pipeline allowing the training, evaluation and prediction using 3 different Autoencoder architectures. CNN, MAE, ResNet50.
The models provided were trained using a dataset with 550 Sentinel-2 satellite images using 8 contigious bands and 1 classification band.
The application also contains an End-To-End dataset curation pipeline. Using a bound box N,E,S,W co-ordinate input tiles are 
downloaded from Earth Engine, Soil Association and OpenTpology then processed into a PyTorch dataset ready for model training, evaluation or prediction.

The application was developed under the Digital Earth initiative https://destination-earth.eu/
